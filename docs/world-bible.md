# 暖湾小镇：异星世界设定

## 目标

把暖湾小镇从“可玩的程序化原型”推进为一个可进入、可观察、可持续扩展的异星生活世界。运行时仍使用 Vite + Three.js；OhMyGame 负责设计协作、参考图、视频、资产生产和代码协作，不替换 Three.js。

## 视觉方向

- 主题：潮汐黏土岛上的异星栖居地，鲜艳、亲和、有生命感。
- 色彩：珊瑚粉、蜜桃橙、薄荷绿、湖水青、紫罗兰和星空靛蓝组成高饱和马卡龙色板。
- 约束：颜色鲜艳不等于全场发光；发光只用于生物荧光、晶体、导航灯和星尘，保留真实阴影、粗糙度和材质层次。
- 形体：角色、房屋和生物使用连续网格、明确轮廓、真实接触关系；禁止用球体、方块堆叠作为最终近景资产。
- 镜头：近景看得到材质和动作，中景能读出生态群落，远景有山脊、云层、星空和空间纵深。

## 首个垂直切片

先完成一条从栖居舱到河谷的可玩路线，不扩张全地图：

1. 栖居舱：可从外部进入，保留外壳、门窗和剖切轮廓；室内布局来自同一套房屋资产。
2. 彩潮草坡：真实起伏路面、分层草地、碎石、花簇和脚下接触阴影。
3. 荧光河谷：有河床、岸线、浅水、瀑布雾气和可辨识的水面流向。
4. 晶脊山口：前景岩体、中景山脊、远景天际线，作为路线视觉终点。
5. 夜空观景点：星云、行星、云层和少量动态星尘，曝光受控，不用全场 Bloom。

## Hero 资产

垂直切片只先做以下资产并完成运行时验证：

- `player-hero`：连续身体网格、骨骼、Idle/Walk/Run/Interact，衣服、鞋、头发和配饰可替换。
- `habitat-pod-hero`：ExteriorShell、InteriorShell、Door_Airlock、CameraCutaway 和家具锚点来自同一 GLB。
- `river-valley-kit`：河床、岸石、浅水、瀑布、湿地材质和碰撞代理。
- `alien-creature-hero`：一种地面生物，具备待机、行走、观察和逃跑行为。
- `alien-tree-hero`：树干、分枝、叶片和荧光花冠，至少 3 个形态变体。
- `sky-and-clouds`：天空穹顶、远景云层、星空和雾层，作为环境系统而非平面贴图。

## 生态分布

资产按群落摆放而不是均匀散布：道路边缘低矮草和碎石，水边湿地植物，晶脊附近晶体与耐旱植物，栖居舱周围有可交互种植区。每种植物至少准备 3 个变体，近景使用完整模型，中远景使用 LOD 或实例化。

## 设计验收

- 角色脚部贴地，走路不漂浮；摄像机不会把角色压成微缩景观。
- 路面有坡度、边缘和材质变化，不是圆形平面岛。
- 河流有源头、河床、岸线和方向感，不是蓝色平面。
- 山川提供远近层次，云层和星空提供垂直空间。
- 房屋进入内部后仍能看见可理解的外框或剖切结构。
- 每个 Hero 资产都有 GLB 加载、材质、尺度、碰撞、动画或交互验收证据。
