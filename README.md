# 暖湾小镇

一个浏览器 3D 治愈系小镇生活原型。自定义原创角色的五官、发型、肤色、穿搭与配饰，在海岛上采集、种植、垂钓、交易、拜访居民、完成小目标、布置院落、骑行，并照料跟随自己的小猫或小狗。日常活动节奏轻松，没有倒计时惩罚。

## 运行与检查

```bash
pnpm dev
pnpm typecheck
pnpm test
pnpm build
pnpm smoke
```

游戏主页是 `/`；静态简体中文介绍网站位于 `/website/`。

## 操作

- **W / A / S / D**：移动；**拖动鼠标**：转动跟随视角。
- **E**：与附近居民、采集物、菜圃、池塘或自行车互动。
- **I**：背包；**C**：角色衣橱；**T**：海湾小集；**J**：任务本；**B**：家园建造；**O**：宠物伙伴。
- **V**：在自行车旁骑行或下车；**R**：建造模式旋转家具；**Esc / P**：关闭菜单、取消建造或暂停。
- 池塘边按 **E** 抛竿；留意浮漂，咬钩后在提示时间内再按 **E** 收竿。
- 手机使用屏幕左下角方向键和右下角互动按钮；底部生活菜单可打开背包、衣橱、任务、市集、建造与伙伴面板。

采集的贝壳、莓果、木料和石料会进入背包；成熟作物可收获并获得贝币。市集支持买入建造材料、鱼饵和宠物零食，以及卖出采集物与鱼获。完成任务领取贝币、种子或物品奖励。建造时挑选家具、把指针移到院落有效位置（绿色预览）、点击放置。

## 存档与版本范围

游戏进度保存在当前浏览器设备的本地存储中，并会将原 v1 存档迁移到 v2 格式；清理浏览器数据会清除本地进度。当前版本是单人原型，不包含账号、真实在线多人、云端存档或排行榜。多人联动仍是未来方向，当前不展示或模拟真实在线玩家。

世界、角色、玩法状态、界面与官网按模块分层，方便后续在具备实际联机服务后继续扩展。本项目的场景与角色使用原创程序化几何，不复制参考作品的具体美术、角色或素材；网站主视觉为原创插画。
